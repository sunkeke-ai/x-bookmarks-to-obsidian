# 从 Chrome 导出 X 收藏 CSV

这份说明只在用户还没有 CSV 时读取。

## 推荐做法

1. 在 Chrome 登录用户自己的 X 账号并打开 `https://x.com/i/bookmarks`。
2. 使用用户信任的表格抓取/网页数据导出插件，选择收藏列表中重复出现的帖子卡片。
3. 至少导出以下字段：帖子原链接（必须）、作者名、X ID / handle、帖子正文或标题、作者头像 URL。
4. 可选字段：作者主页、发布时间、文章标题、文章摘要、回复、转发、喜欢、浏览量和帖子图片。
5. 让插件持续滚动并确认达到收藏列表底部，然后导出 UTF-8 CSV。

## 对用户的简短提示词

导出完成后，可以把 CSV 附给 Codex 并说：

> 使用 `$x-bookmarks-to-obsidian` 整理这份 X 收藏 CSV，去重后按用途分类，生成到我的 Obsidian，名称叫“x收藏夹”。保留原链接，并建立可置顶的作者卡片页。

## 输入兼容

构建脚本支持两类 CSV：

- 有清晰列名的常规 CSV，例如 `url`、`author`、`handle`、`text`、`avatar_url`、`views`。
- 浏览器表格抓取插件导出的 CSS 选择器列名 CSV。对这类文件，脚本按照经过验证的 X 帖子卡片列顺序识别字段，并在预览报告中标记为 `positional-css-export`。

如果插件导出的列顺序不同，先重命名为常规列名，不要猜测错位字段。

## 隐私与安全

- 不要求导出 Cookie 或登录凭证。
- 不把 CSV 上传到公共网盘或临时分享网站。
- 浏览器自动操作只在用户当轮明确授权后进行，并保持只读。
